# 架构与设计取舍

这份文档讲**为什么这么设计**，不讲怎么实现。实现细节在私有仓库。

---

## 一、三层结构

```
接入层   MCP（33 工具，SSE + Streamable HTTP 双传输） / REST / WebSocket / 看板前端
         ↓ 外部 agent 可自述加入：join_context → list_pending_turns → claim_turn
引擎层   角色槽位调度 · 轮次推进 · 共识判定 · 相关性守卫 · 主持 Agent · 结构化决策卡 · 校验层 · 评审 Agent
         ↓
数据层   会话实例 JSON（原子写 + 串行化） · 共识版本链（supersede） · 审计流水 · 工单 · 产物
```

单一 Node 进程，4 个 npm 依赖，零 GPU，零数据库。

## 二、一次评审的数据流（九步）

| 步 | 做什么 | 关键约束 |
| --- | --- | --- |
| 01 提议题 | 用户给一句话或一份文档 | **原话一字不改**，AI 只允许另起标题 |
| 02 Agent 编排 | 先审题三步（核心问题 / 视角穷举 / 自曝盲区），再配角色槽位与轮数 | 简单题 3 个角色、不设主持 Agent；有分歧才加主持 Agent |
| 03 多角色多轮讨论 | 每个角色独立人格、立场、模型；互相引用上一轮 | 角色槽位身份用**角色名**，不用工具名 |
| 04 相关性守卫 | 每轮对议题打相关度 0-10 | 连续 2 轮 <6 拉回，仍低即停 |
| 05 共识判定 | 接受=1 / 部分接受=0.5 / 拒绝=0，加权均值 | 均值 ≥0.6 且**连续 2 轮**才算收敛 |
| 06 结构化决策卡 | 结论 / 假设 / 去水 ROI / 隐性成本 / 人工 vs AI 锚点 / 风险等级 / 建议动作 | 全文 ≤520 字，必须出现数字 |
| 07 独立评审（LLM-as-a-Judge） | 只判通过 / 不通过，附 3-5 条致命漏洞 | 按议题类型动态选角（投资→审计师，运营→店长） |
| 08 校验层（Validators） | 规则化判据 + 算式真值 | 不过就打回重审，最多 2 轮，再不过交人 |
| 09 任务交接（Handoff） | 共识 → 工单 → 认领 → 回写证据 → 验收 | 全程审计留痕 |

## 三、角色槽位是什么

一个角色槽位 = **base（行业基准）+ persona（人格）+ model + backend**。

- `base` 决定给它注入哪一段行业权威基准（PMBOK / 国标 / COSO / ISO 等），自定义角色只给纪律不给数字；
- `persona` 决定它怎么说话、专挑什么毛病；
- `backend` 决定电话走 MCP 外部 agent 还是本机 HTTP。

每个角色槽位开口前，系统会把五样材料摆到它面前：**准则硬规则、会话实例记忆、技能库目录、行业上下文、议题事实基准（带来源 URL 与发布日期）**。

## 四、六个刻意的取舍

**1. 为什么不用向量数据库做记忆？**
数据量级是「一个会话实例几千条发言」，用 JSON 全量加载 + 关键词检索就够。向量库会引入不可解释的相似度，而这个项目的核心诉求是**可复算**——每条结论要能追到哪一轮谁说的。不可解释的召回，在评审场景是负资产。

**2. 为什么收敛判据是代码，不是让模型自己判「差不多了」？**
因为模型判收敛不可复算。代码判据至少能被回放验证：拿 48 条历史发言回测，第 9 轮触发，和实跑对得上。判据错了能改判据，模型「感觉对了」没法查。

**3. 为什么反对词表要限定第一人称？**
宽词表会把「他说的那点站不住，但我同意主体方案」判成反对。实测误报 4 条，改严格第一人称后降到 0。**误判比漏判贵**。

**4. 为什么决策卡的「隐性成本」必须写「若…则…」？**
因为不写推演的隐性成本，等于没算。这一条是硬闸的一部分，缺了直接打回，不看模型怎么解释。

**5. 为什么不做自动联网检索？**
自动检索会让来源不可控——模型可能引用一个看起来权威但无法复现的页面。当前方案是半自动：人工注入白名单事实（带 URL 和发布日期），模型只能在给定范围内引用。**宁可少知道，不可假知道。**

**6. 为什么坚持原话不改？**
议题是评审对象。AI 顺手把长议题压成摘要，等于替用户改了题，后面所有结论都在评一个别的东西。这条踩过坑：代码里曾写了 `topic = summary || value`，被用户当场发现。

## 五、它不做什么

- 不做开放式头脑风暴（那是聊天机器人的活）；
- 不做全公司 SaaS（单机单进程，一个团队一个实例）；
- 不做法律级存证（审计是应用级留痕）；
- 不训练、不微调（智能全部来自自备 API key）。
